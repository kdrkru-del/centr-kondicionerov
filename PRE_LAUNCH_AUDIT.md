## 2. Результаты проверки ключевых задач

### 2.1. Решение по `/uslughi` -> Создание `/installation`
- **Проблема:** Редирект на якорь `/#installation` мог привести к потере ценного коммерческого интенса («установка кондиционеров во Владивостоке»).
- **Решение:** Создана полноценная SEO-страница `/installation` ([src/app/installation/page.tsx](file:///c:/Users/roman/OneDrive/Документы/project/centr-kondicionerov/src/app/installation/page.tsx)). В неё перенесены подтверждённые стандарты монтажа (2–4 часа, без пыли, фреоновая трасса, вакуумирование, запуск, обучение). Устаревшие разрозненные сметы из старого сайта не навязываются как сегодняшние, цены идут прозрачно «под ключ» из каталога. Старый URL `/uslughi` получил прямой permanent 301/308 редирект на `/installation`.

### 2.2. Решение по `/o_kompanii`
- Страница на старом сайте содержала типовой промо-текст, перенесённый в `WarrantySection` и `BrandsSection`. Настроен постоянный 301 редирект `/o_kompanii` -> `/#warranty`.

### 2.3. Решение по `/mdvprom`
- Полупромышленные кондиционеры MDV на старом сайте содержали заявку «от 73 900 ₽» без наличия на складе. В текущем каталоге представлены проверенные серии. Настроен безопасный постоянный 301 редирект `/mdvprom` -> `/catalog/mdv`.

### 2.4. Решение по `/novosti` и `/aktsii`
- Старые разделы новостей и акций не содержали индивидуальных индексируемых статей (акций с истёкшим сроком нет). Настроен редирект в основной каталог `/catalog`.

### 2.5. Проверка форм и отправки лидов
- **Устранена критическая ошибка:** Ликвидирована логика `catch { setIsSuccess(true) }`. Формы теперь строго проверяют `res.ok` и выводят ошибку при сбое сети, не дезинформируя клиента.
- **Инфраструктура доставки заявок:** Роут `/api/lead` валидирует телефон, формирует структурированный лог и готов отправлять уведомления в Telegram при указании `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env.local`. Создан шаблон `.env.example`.
