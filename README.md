# README.md

# «Центр Кондиционеров» (Владивосток, Артём, Уссурийск)

Официальный веб-сайт компании «Центр Кондиционеров». Продажа, доставка и профессиональная установка климатической техники ведущих брендов: MDV, AMSTON, DAHATSU, HUNBERG.

## Стек технологий

- **Фреймворк:** Next.js 16 (App Router, Turbopack)
- **Библиотеки:** React 19, Lucide React
- **Стилизация:** Tailwind CSS v4
- **Язык:** TypeScript 5
- **Аналитика:** Яндекс.Метрика (счетчик ID: `101376260`) со встроенным Вебвизором
- **Семантика и SEO:** Schema.org (JSON-LD: LocalBusiness, Product, CollectionPage, Breadcrumbs, FAQPage), OpenGraph, dynamic sitemap.xml, robots.txt

---

## Установка и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Сайт будет доступен по адресу [http://localhost:3000](http://localhost:3000).

### 3. Сборка production-версии
```bash
npm run build
```

### 4. Локальный запуск production-сервера
```bash
npm run start
```

## Переменные окружения (.env)

Для локальной настройки скопируйте `.env.example` в `.env.local`:
```bash
cp .env.example .env.local
```

Доступные переменные:
- `TELEGRAM_BOT_TOKEN` — токен бота для получения заявок с сайта
- `TELEGRAM_CHAT_ID` — ID чата/группы менеджеров для уведомлений

---

## Структура данных и каталога

- `src/config/company.ts` — единый источник истины для контактов, телефонов, городов присутствия и подтверждённых формулировок
- `src/data/products.ts` — проверенная база сплит-систем (ровно 13 позиций, подтверждённых аудитом)
- `src/data/brands.ts` — карточки брендов MDV, AMSTON, DAHATSU, HUNBERG
- `src/data/cities.ts` — данные городов обслуживания
- `src/data/faq.ts` — подтверждённые ответы на частые вопросы
